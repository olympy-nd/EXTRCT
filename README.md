# أداة التسوية المصرفية

أداة تعمل داخل المتصفح لمطابقة كشف المصرف مع دفتري الفرع والادارة قيداً بقيد، وإعداد مذكرة التسوية المحدّثة وقيود الإقفال، وتصدير النتائج إلى Excel.

كل المعالجة تتم على جهاز المستخدم، ولا تُرفع الملفات إلى أي خادم.

## الاستخدام

1. افتح الأداة من رابط GitHub Pages، أو افتح `index.html` مباشرة في المتصفح.
2. ارفع كشف المصرف ودفتراً واحداً على الأقل (الفرع أو الادارة) بصيغة xlsx أو xls.
3. فعّل «وضع التسوية» وارفع ملف مذكرة التسوية إن أردت إضافة حركاتها إلى المطابقة. تُقرأ آخر ورقة في الملف.
4. اختر شرط التاريخ، ثم اضغط «تشغيل المطابقة».
5. راجع الأوراق من القائمة الجانبية، ثم صدّر النتائج بزر «تصدير Excel».

## الأوراق

- الملخص، ومذكرة التسوية المحدّثة، ومذكرة التسوية المرفوعة
- حركات بلا قيد، والمصروفات المصرفية
- دفتر الفرع: المتطابق، غير المتطابق، القيد، التسويات السابقة
- دفتر الادارة: المتطابق، غير المتطابق، القيد، قيد الإقفال

## البيانات المرجعية

دليل الحسابات ودليل حسابات الإقفال (حسابات الحوالات المعلقة) مضمّنان في الأداة، ويمكن استبدال أيٍّ منهما برفع ملف Excel من قائمة «المزيد».

## المتطلبات

متصفح حديث واتصال بالإنترنت لتحميل مكتبة SheetJS من CDN عند فتح الصفحة.
